# Sample datasets (synthetic)

Every file in this folder is **artificial**, generated by `generate_samples.py`
with a fixed random seed. They exist to demonstrate and test NexusRaid; they are
not real measurements. The patterns deliberately injected into each file are
listed in `INJECTED_PATTERNS` inside the generator, so you can check whether the
analysis finds what was actually put there.

Regenerate: `python samples/generate_samples.py` (from the repository root).
